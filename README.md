# Zansti AI — سیستەمی یاریدەدەری وانە

ئەم پڕۆژەیە بۆ ٤ وانە دروست کراوە:
- زیندەزانی 🧬
- فیزیا ⚡
- کیمیا ⚗️
- بیرکاری ∑

## ٣ بەشی سەرەکی
1. **کورتەی بابەت** — گرنگترین خاڵەکان.
2. **ڕوونکردنەوەی زانستی** — مامۆستایەتی، هەنگاو بە هەنگاو.
3. **ڕاهێنان و تاقیکردنەوە** — پرسیار بۆ دڵنیابوون لە تێگەشتن.

## دامەزراندنی AI
Node.js 18+ پێویستە.

```bash
npm install
cp .env.example .env
```

لە `.env` ـدا API key ـەکەت دابنێ، پاشان:

```bash
npm start
```

لە browser:
`http://localhost:3000`

**تێبینی:** API key تەنها لە server هەڵدەگیرێت؛ لە `app.js` دانەمەزرێنە.

ئەم وەشەنە Responses API بەکاردێنێت و وێنەی وانەش وەک input_image دەنێرێت. OpenAI لە 2026دا Responses API ـی بۆ integration ـە نوێکان بەکاردهێنێت و Assistants API لە 26ی August 2026 کۆتایی پێهاتووە.


## Login و 100 کۆد
`credentials.txt` ـدا 100 یوزەر/کلیل هەیە.
- هەر یوزەر یەکجار دەتوانێت بە یەک Device ID ببەسترێت.
- دوای bind بوون، لە browser/device ـی تر login ناکات.
- لەبەر ئەوەی IP ـی مۆبایل دەتوانێت بگۆڕێت، سیستەمەکە Device ID بەکاردهێنێت، نە IP تەنها.
- بۆ بەرهەمی ڕاستەقینە، `users.json` باشترە لە database بگۆڕدرێت و session ـەکان لە Redis/DB هەڵبگیرێن.
